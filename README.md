**Introduction du projet :**

Dans le cadre de mon BTS SIO option SLAM, j’ai développé un site vitrine pour une pizzeria située à Upie (Drôme), en mettant en pratique mes compétences en HTML, CSS et PHP. 
Ce projet m’a permis de concevoir une interface fonctionnelle et attrayante, répondant aux besoins réels du client.

**Yo'Upie Pizza V2 :**

La première version du site se limite à une interface en HTML et CSS, permettant aux clients de consulter rapidement la carte. 
Elle est compatible PC, tablette et mobile, et hébergée gratuitement via le service Pages de Cloudflare, qui permet aux développeurs indépendants d’héberger des projets HTML/CSS/JS.
Cette V1 permet également de recueillir des avis clients sur l’identité visuelle du site et son ergonomie, afin d’orienter les améliorations futures.
