**Introduction du projet :**

Dans le cadre de mon BTS SIO option SLAM, j’ai développé un site vitrine pour une pizzeria située à **Upie** (Drôme), en mettant en pratique mes compétences en **HTML, CSS et PHP**. Ce projet m’a permis de concevoir une interface fonctionnelle et attrayante, répondant aux besoins réels du client.

**Yo'Upie Pizza V2 :**

La deuxième version du site intègre une **base de données**, rendant le site dynamique. En utilisant **PHP**, j’ai créé une base de données qui stocke la carte des pizzas ainsi que celle des boissons. Cette V2 permet non seulement de générer une carte dynamique, mais aussi d’implémenter des fonctionnalités supplémentaires, comme un système de filtres pour faciliter la navigation.

Cette version adopte le modèle de programmation **MVC (Model, View, Controller)**, ce qui permet d’organiser le code de manière structurée, d’améliorer la sécurité du site et de sa base de données, et de faciliter la maintenance et les évolutions futures.
